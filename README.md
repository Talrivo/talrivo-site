# TALRIVO Website Draft

This is a static English B2B inquiry website for the new independent
`TALRIVO` brand. The domain `talrivo.com` was purchased through Alibaba
Cloud Wanwang on 2026-05-26. Open `index.html` in a browser to preview it.

## Included

- Conversion-focused home page with actual headset images.
- Product category filtering for wireless, RGB wired and accessory ranges.
- Complete catalogue viewer with 27 product directions and 111 prepared images.
- Product detail gallery with dedicated video position; six existing video
  candidates are linked for model review where the product match is clear.
- OEM/ODM coordination and quality documentation messaging.
- RFQ form that prepares an inquiry email to the official inquiry mailbox
  `sales@talrivo.com`.

## Launch Status

- Public site is live at `https://talrivo.com`.
- GitHub Pages custom domain and HTTPS are configured.
- Search indexing is enabled, with `robots.txt` and `sitemap.xml` added.

## Backend Recommendation

This local site is the design and content draft. For an owner-managed website,
publish it through a WordPress installation with a product content type. Each
product record should include:

- model and public product title;
- product category and hero image;
- image gallery;
- product video URL or uploaded media field;
- specifications, MOQ, sample terms and compliance attachments;
- inquiry button linked to the RFQ form.

Do not place customer lists, commercial quotation sheets, or supplier certificates
in the public media library unless explicitly approved for publication.
