# TALRIVO

This repository publishes the TALRIVO website at
https://talrivo.com.

TALRIVO presents documented gaming headset models, product videos and
sample-review information for importers, distributors, brands and OEM/ODM
buyers.

For product or sample enquiries, contact sales@talrivo.com.

## Public source policy

Customer records, credentials, analytics exports, internal diagnostics and outreach
working documents belong outside this public repository. Build exclusions only
control the published website bundle; they do not hide files on GitHub. Deleting
a file in a later commit does not remove historical copies.

The public editing guide remains at `marketing/content-publishing-guide.md`.
Image masters referenced by the build scripts, product data and source code are
retained as build dependencies.
