## Hypothesis, Not Result

A visitor should recognize the product type, connection choices and available evidence before clicking. The old description starts with isolated parameters and omits the connection choices. This is a clarity hypothesis; it is not evidence that the old description caused low CTR. Google may generate a different snippet for each query.

3. D+7: check crawl/indexing problems only. Do not rewrite again based on one click or a daily fluctuation.
4. D+28: compare equal 28-day windows for this exact page, Web search, matching country/device filters. Export totals and query rows separately.
5. Separate G938 model queries from non-brand wireless/tri-mode/OEM/private-label queries. Compare the same queries and approximate position ranges where possible; show impressions, clicks, CTR and query coverage. Do not add overlapping country/device totals.
6. If clicks are too sparse or query coverage is insufficient, label the result inconclusive. Neither a CTR rise nor a fall alone proves causation. Other recent site changes are confounders; this is not a randomized A/B test.
